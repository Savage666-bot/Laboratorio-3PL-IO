# Laboratorio 3PL IO

Suite de Investigación de Operaciones que corre en el navegador (un solo archivo `index.html`):

- **Modelador PL**: programación lineal y entera con sintaxis de LINGO, rangos de sensibilidad y análisis paramétrico.
- **Input Analyzer**: ajuste de distribuciones (Fit All, Square Error, chi-cuadrado y Kolmogorov-Smirnov).
- **Prueba de bondad**: chi-cuadrado y KS paso a paso.
- **Simulador tipo Arena**: diagrama con módulos Basic Process, réplicas y reporte Category Overview.
- **Monte Carlo**: variables aleatorias, probabilidades y sensibilidad.

Todo se calcula en el navegador: no se envía ni se guarda ningún dato en servidores.

No es LINGO ni Arena; no está afiliado a LINDO Systems ni a Rockwell Automation.
